# AutoPPT会议内容工作台

工作台提供会议PPT和会议海报两项功能。PPT功能按日程复制模板页面并填入专家资料，输出可编辑PPT。海报功能从图片日程中识别会议内容，按姓名匹配专家头像，参考海报模板的比例与主色生成高清PNG。运行过程不调用大模型，不需要API密钥，不向外部服务发送资料。

## 启动

普通用户可直接运行`release/AutoPPT-Setup-v1.0.0.exe`完成安装。安装程序会创建桌面和开始菜单快捷方式，目标电脑无需安装Python或Microsoft Office。双击AutoPPT快捷方式后会自动打开浏览器，关闭运行窗口即可停止本地服务。

在当前电脑上双击`start.bat`，浏览器会打开本地工作台。双击`stop.bat`可以快速停止服务，也可以关闭启动窗口或在窗口中按Ctrl+C停止。

访问地址为http://127.0.0.1:8765。项目已配置为优先使用当前电脑的本地依赖运行时。

在其他电脑部署时，安装Python3.10或更新版本，然后在项目目录执行：

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

依赖包括lxml、Pillow和RapidOCR本地识别组件。安装依赖需要联网，日常生成不需要联网。无需安装Microsoft Office即可完成文件生成。

## 生成会议PPT

1. 上传多份专家DOCX、WPS、PPTX，或专家资料ZIP压缩包。
2. 上传1份日程PPTX和1份串场模板PPTX。
3. 查看识别结果，可修改会议名称、日程、专家简介、展示单位和照片。
4. 查看模板识别结果。程序自动推断页面角色和填充区域，识别不完整时可在界面调整。
5. 点击生成，下载PPT及核对报告。

界面提供input和input1示例入口。源文件保持不变，网页任务及其生成文件保存在`work`目录。

## 生成会议海报

1. 在首页选择生成会议海报。
2. 上传以专家姓名命名的PNG、JPG或WEBP头像，也可以上传包含这些头像的ZIP压缩包。
3. 上传1张日程图片和1张海报模板图片。
4. 本地OCR自动识别会议名称、日期、会议号、主席、主持、讲题和嘉宾名单。
5. 核对识别结果，调整专家单位、称呼和海报分组。
6. 点击生成，预览并下载高清PNG海报。

海报按会议主席、会议主持、会议讲者和讨论嘉宾分组。头像统一裁成圆形，日程按主持变化自动插入分段栏。模板中的旧文字不会进入输出，程序保留模板比例、主色和顶部两侧机构标识。

## 默认规则

- 每次分析上传的模板，不依赖固定页码、文本框名称或专家名单。
- 复制原始页面，保留背景、标志、形状坐标、母版、主题及可编辑对象。
- 姓名、单位、简介、讲题和照片定点替换。相同文字保留原有排版。
- 按日程生成页面。双主席、多位讲者、多场会议及多人讨论均可处理。
- 专家介绍只占一页并最多保留12行。第一行放医院、科室及临床职务职称，随后优先放学历、导师或学校履历，再按原资料出现顺序补充社会任职及其他履历。学校信息缺失时直接承接社会任职，不保留空行。
- 每位专家最多显示12条真实资料，缺失类别不显示。新文字合并继承模板文字片段、段落及文本框默认样式中的字号、字体、颜色、粗细和行距，模板容量不足时精简低优先级内容并在核对报告中提示。
- 核对报告保留简介原文、精选内容及未选社会任职，便于追溯和调整。单行过长时按模板容量自动精简，模板文字格式保持不变。
- 原生表格按行读取，段内换行保留；文本框日程结合页面位置关联。
- 照片按专家资料中的旋转和翻转方向校正，再等比放大并居中裁切，充满模板图片框并保留原照片背景。当前不提供抠图。
- 同一模板生成成功后保存区域配置，再次上传完全相同文件时复用。配置位于`work/template_profiles`。
- 同名简介、无法确定的照片、缺失简介及无效日程会记录为核对提示，仍然继续生成可编辑PPT。
- 可主动选择待核对模式。缺失专家页面显示简介待补充，旧人物照片会清除。
- 模板中的讨论话题默认排除，可选择每场保留原文，使用者需确认适用性。
- 不继承模板的旧演讲备注和自定义放映章节，删除未使用的旧页面及其不再引用的照片。
- 替换图片时同步更新替代文字，防止旧姓名残留在图片说明中。

## 支持范围与边界

当前版本面向具有可编辑文字和独立照片的中文会议串场PPT。专家简介支持DOCX、WPS和PPTX格式。程序综合页面文字、对象位置、图片比例和重复结构推断封面、人物页、讲题页、讨论页及结束页。缺少某类专用页面时，会选择相近页面布局继续生成。

海报功能支持清晰的中文日程图片，以及PNG、JPG、JPEG、WEBP格式的头像和模板。头像文件名需要包含专家姓名。低清图片、严重倾斜图片和复杂手写日程可能需要在核对页面手工修正。

完全图片化的模板、扫描件、PDF、旧版DOC或PPT暂不支持。复杂SmartArt、姓名嵌入背景、动态字段位于母版中、特殊表格布局等情况需要在界面调整普通文本框映射，或先整理源模板。

未知模板会先自动识别可编辑区域，无法识别的内容保留空白或原布局，并写入核对报告。缺少会议名称、日期、专家资料或部分模板区域时仍会生成PPT。输出页数根据议程变化。

字号和文本容量使用本地字体进行估算，并保留排版余量。网页显示对象结构预览，未启动Office渲染器。生成报告中的visual字段默认标记为not_rendered，正式会议前应检查PowerPoint或WPS中的实际效果。不同电脑的字体可能影响换行。

当前任务记录保存在运行进程内，服务重启后网页任务需重新导入，已下载文件及`work`中的结果保留。模板区域配置可跨重启复用。删除`work`中的历史任务目录即可清理本地资料，请先保留需要的结果。

## 命令行

```powershell
# input目录缺少朱帅独立简介，示例使用待核对模式。
python app.py --input input --draft --output output/临床营养会议_待核对.pptx

# input1资料完整，可正常生成。
python app.py --input input1 --output output/胸部肿瘤会议.pptx

# 只分析，输出结构化结果。
python app.py --input input1 --analyze-only

# 指定文件，不依赖目录中文件的命名规则。
python app.py --template 模板.pptx --agenda 日程.pptx --experts 简介.zip --output output/会议.pptx
```

其他参数：`--include-topics`保留讨论话题，`--no-repeat-chairs`取消总结后的重复主席介绍，`--port`改变端口，`--no-browser`启动时不打开浏览器。

## 验证

```powershell
python -m unittest discover -s tests -v
```

测试覆盖真实资料匹配、多类日程解析、缺失内容容错、ZIP重复去重、不安全路径、精选简介完整性与单页约束、旧姓名清除、母版与坐标保留、任意对象编号、8套近期模板适配、客户端路径隔离以及本机HTTP服务。

`tools/render.mjs`是开发用可选渲染脚本，需要本地已安装的artifact-tool模块。它用于检查生成页面，不参与生产生成流程。当前电脑的样本渲染检查文件保存在`.build`目录。

## 文件结构

| 路径 | 用途 |
|---|---|
| app.py | 网页及命令行入口 |
| autoppt/ooxml.py | Office结构读取和安全解压 |
| autoppt/analyze.py | 专家、日程和模板识别 |
| autoppt/generate.py | 模板填充、分页及校验 |
| autoppt/poster.py | 海报OCR解析、头像匹配和PNG绘制 |
| autoppt/server.py | 本机上传和任务接口 |
| web | 网页界面 |
| tests | 回归测试 |
| output | 命令行生成示例 |
| work | 网页任务、识别结果及模板配置 |

本项目基于多组真实资料和8套近期模板实现并验证。程序会在结构允许时持续生成，并把需要人工复核的内容写入核对报告。正式会议前仍需在PowerPoint或WPS中检查实际换行和视觉效果。
